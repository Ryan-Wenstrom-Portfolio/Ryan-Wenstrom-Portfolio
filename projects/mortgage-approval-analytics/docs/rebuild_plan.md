# Rebuild Plan

This project currently includes the cleaned portfolio documentation, dashboard screenshots, methodology notes, limitations, and claim audit. The original cleaned analytical dataset is not stored in this repository at this time.

## Current Status

* Tableau dashboard screenshots are included.
* Project methodology and limitations are documented.
* Data source notes are included.
* The cleaned analytical dataset is not currently included.
* A reproducible Python notebook will be added after the cleaned dataset is recovered or rebuilt.

## Planned Rebuild Steps

1. Recover or recreate the cleaned analytical dataset from the 2017 HMDA source files.
2. Verify row counts, field names, filters, and recoded variables against the documented project results.
3. Export a clean CSV suitable for portfolio analysis.
4. Create a Python notebook that reviews the cleaned dataset and reproduces key summary statistics.
5. Add summary tables for approval rate by state, race-gender group, income group, and property type.
6. Compare notebook outputs against the Tableau dashboard results.
7. Update the README with notebook links and reproducibility instructions.

## Reproducibility Standard

The future notebook should run from top to bottom without errors, use relative file paths, avoid course assignment language, and clearly separate verified results from interpretation.

## Publication Standard

Before this repository is made public, the project should be reviewed for:

* No course assignment prompts
* No private or restricted files
* No unsupported technical claims
* No hidden credentials or local file paths
* No misleading causal claims
* Clear data source attribution
* Clear limitations
