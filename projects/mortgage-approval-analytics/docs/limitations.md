# Limitations

This project is a descriptive analytics project. It identifies patterns in mortgage application outcomes but does not prove why those differences occurred.

## Main Limitations

1. The analysis does not include every variable used in mortgage underwriting.
2. Approval differences should not be interpreted as proof of discrimination or causation.
3. The selected states are not a statistically representative sample of the entire United States.
4. Some variables reflect census tract or geographic context rather than individual applicant characteristics.
5. The project focuses on favorable decision outcomes and does not fully model all possible application statuses.
6. Dashboard findings are intended for exploration and hypothesis generation, not final legal, lending, or policy conclusions.

## Responsible Use

This project should be used as a portfolio demonstration of data cleaning, transformation, dashboarding, and analytical communication. It should not be used to make lending, compliance, legal, or policy decisions without deeper statistical review and domain expertise.
