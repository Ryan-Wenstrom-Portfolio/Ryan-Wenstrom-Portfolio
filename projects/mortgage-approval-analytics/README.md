# Mortgage Approval Analytics

A portfolio data analytics project using public 2017 Home Mortgage Disclosure Act data from California, Illinois, Michigan, and Texas.

## Project Goal

This project demonstrates how raw public mortgage application data can be downloaded, cleaned, stored, queried, validated, and transformed into an analytical dataset for Tableau.

## Tools

- Python
- pandas
- PostgreSQL
- SQL
- Tableau Public
- Git and GitHub

## Planned Workflow

1. Download official 2017 HMDA data.
2. Inspect and standardize the raw fields.
3. Clean and validate the records with Python.
4. Store the complete four-state dataset in PostgreSQL.
5. Query and summarize the data with SQL.
6. Export a Tableau-ready analytical dataset.
7. Build interactive Tableau dashboards.
8. Document the methodology, findings, and limitations.
