# Dashboard Visuals

This folder contains exported screenshots from the Tableau dashboard portion of the Mortgage Approval Analytics project.

## Visuals Included

### Dashboard 1: Overview
High-level view of mortgage application approval patterns across selected states and applicant groups.

### Dashboard 2: Subgroup Analysis
Compares approval rates across applicant income groups, race-gender segments, and property types.

### Dashboard 3: Geographic Context
Explores geographic and income-context patterns across the selected HMDA state samples.

## Notes

These screenshots are included for portfolio review and are not meant to replace the interactive Tableau workbook. The dashboards are intended for exploratory analysis and should not be interpreted as causal or legal conclusions.
